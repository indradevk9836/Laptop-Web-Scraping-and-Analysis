# Laptop-Web-Scraping-and-Analysis

A data analytics project that scrapes laptop product data from Flipkart using Python and BeautifulSoup, cleans and transforms the data, and performs SQL-based analysis using MySQL.

## 📌 Project Overview

This project focuses on extracting laptop product information from Flipkart and analyzing the collected data to identify patterns in pricing, brands, specifications, ratings, reviews, and discounts.

## 🎯 Objectives

- Scrape laptop product data using Python and BeautifulSoup.
- Clean and preprocess the scraped dataset.
- Store the processed data in MySQL.
- Perform exploratory data analysis using SQL.
- Analyze laptop pricing, specifications, ratings, reviews, and discounts.

## 🛠️ Technologies Used

- Python
- BeautifulSoup
- Requests
- Pandas
- MySQL
- SQLAlchemy
- SQL
- Jupyter Notebook
